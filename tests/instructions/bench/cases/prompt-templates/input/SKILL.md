# Triaging invoice disputes

**You dispatch two workers per customer: a summary worker, then a review worker.** You read their reports and decide each dispute yourself.

## Steps

1. Read `references/dispatch.md`.
2. Fill the summary template for the customer, and send it, per `references/dispatch.md`.
3. When the summary arrives, fill the review template with the refund decisions it proposes, and send it.
4. Decide each dispute from the two reports, and tell the user each decision.
