# Design handoff

**A design worker writes options, recommends one, and prototypes it.**

## Fill

1. Copy `templates/design.md` to the handoff file, per `SKILL.md` Dispatch.
2. Quote the roadmap item verbatim.
3. Quote every settled rule the design touches. The Conformance section checks the design against these quotes.
4. Write examples that every option MUST handle, such as programs, inputs, or calls. Include one example where you expect the options to differ.
5. Write each question openly, per `prompt-standards.md`. NEVER hint at the option you expect.
6. Replace every `<placeholder>`. Delete each template line that does not apply.
